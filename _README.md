# limitlessgoals.ae

Static site for Limitless Goals Import & Export Services. Hosted on GitHub Pages (repo mansour200326/limitlessgoals-site), custom domain in `CNAME`.

- Edit pages in `_src/` (shared header/footer/head live in `_build.py`), then run `python3 _build.py`.
- Files/folders starting with `_` are not published by GitHub Pages (Jekyll), so `_src/`, `_build.py` and this file stay out of the live site.
- Enquiry forms (contact.html, ar/index.html) post to FormSubmit (https://formsubmit.co) → info@limitlessgoals.ae.
  The first real submission sends an activation email to info@limitlessgoals.ae: click "Activate Form" once.
- Privacy pages were generated from Wakeel's template by ~/projects/leads/kit/privacy.mjs (vars: ~/projects/limitless/legal/privacy.json). Regenerate instead of editing.
